# NLP Mail Classifier (Hackathon Project)

Система автоматической классификации входящих писем с использованием методов обработки естественного языка (NLP). Проект написан на Python и предназначен для парсинга, токенизации и интеллектуальной сортировки текстовых файлов по смысловым категориям.

## Особенности

* **NLP-обработка:** Использование `razdel` для токенизации русскоязычного текста и `nltk` (SnowballStemmer) для стемминга.
* **Гибкая система правил:** Классификация по заранее заданным категориям (инциденты, доступы, финансы, встречи, спам, безопасность и др.).
* **Распознавание логов и ошибок:** Регулярные выражения для перехвата кодов ошибок (`ERR_500`, `404`) и системных алертов.
* **Безопасность:** Игнорирование бинарных и потенциально опасных форматов (`.exe`, `.bin`, `.zip`).
* **Удобное управление:** Автоматизированный bash-скрипт `run.sh` для установки зависимостей, запуска, очистки и тестирования (с поддержкой менеджера пакетов `uv`).

## Структура проекта

```text
├── data/
│   ├── inbox/          # Директория для входящих писем (поместите сюда ваши .txt файлы)
│   └── outbox/         # Директория для отсортированных писем по категориям
├── tests/              # Unit-тесты для проверки логики (на базе pytest)
├── verison.py          # Основной скрипт классификатора (логика NLP и маршрутизация)
├── requirements.txt    # Зависимости проекта
└── run.sh              # Bash-скрипт для быстрого управления проектом

Установка и настройка
Убедитесь, что у вас установлен Python (скрипт также поддерживает быстрый менеджер пакетов uv, если он установлен в системе).
1. Склонируйте репозиторий и перейдите в папку проекта.
2. Установите необходимые зависимости с помощью bash-скрипта: ./run.sh setup
Использование
Для запуска программы необходимо предварительно создать директорию data/inbox (если она отсутствует) и поместить туда текстовые файлы для классификации.
Управление проектом осуществляется через run.sh:
• Запуск классификатора: ./run.sh run Скрипт проанализирует файлы из data/inbox и переместит их в соответствующие папки внутри data/outbox.
• Возврат писем обратно (очистка outbox): ./run.sh clean Возвращает все отсортированные файлы обратно в inbox и удаляет структуру папок в outbox.
• Запуск тестов: ./run.sh test Запускает набор unit-тестов из папки tests с помощью pytest.
• Полный цикл (очистка, тесты, запуск): ./run.sh all
Классификатор (Категории)
Программа умеет распределять письма по следующим основным категориям:
• incidents — сбои, проблемы, зависания
• access_and_hr — доступы, пароли, отпуска
• finance_and_docs — счета, акты, договоры
• meetings — встречи, созвоны
• security_alerts — взломы, блокировки
• spam — реклама, скидки, казино
• errors / alerts / logs_info — системные ошибки и логи
• unclassified (бинарные файлы) / unsorted (нет совпадений)
